# Niedvin Modpack for World of Tanks EU

Download [the current modpack](https://github.com/Niedvin/WOT-Mod-Launcher/releases/latest) for World of Tanks EU 2.4.1.1.

1. Close World of Tanks and extract the `mods` folder from `Niedvin_WoT_Modpack.zip` into the game folder beside `version.xml`.
2. Start the game from Wargaming Game Center. The **Моди** button is in the hangar footer, to the left of the system icons.
3. Scroll through the mods and their settings with the mouse wheel. Settings save as you change them. For package switches that need a new session, select **Перезапустити гру**.

The manager archives installed copies of ModsSettings API and ModsList API once. If the client has those files open, the manager moves them as soon as the client closes.

The ZIP includes the default selection. Optional mods remain available as individual downloads. The release's `manifest.json` lists their installation subfolders, versions and SHA-256 hashes.

Build instructions are in [docs/BUILD.md](docs/BUILD.md).
